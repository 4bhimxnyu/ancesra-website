# ancesra ai — website

The landing page for [ancesra ai](https://github.com/4bhimxnyu/Nexus-releases/releases/latest), a free AI assistant that runs 100% offline on your laptop.

Live: https://ancesra.vercel.app

Built with Next.js (App Router), from the Figma "Landing — v2 (editorial)" design.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

- `app/page.jsx`: the page, section by section
- `app/globals.css`: all styles (design tokens at the top)
- `lib/links.js`: the download and other outside links, in one place
- `public/assets`: logo, app previews, glow and arrow graphics

Deployed on Vercel. Urbanist font: SIL Open Font License (`app/fonts/OFL-Urbanist.txt`).
